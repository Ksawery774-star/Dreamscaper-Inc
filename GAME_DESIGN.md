# Game Design Document - Dreamscaper Inc.

## Core Loop
1. Management phase in the agency hub
2. Dive into client's dream (roguelite run)
3. Return with trauma resolution / new scars

## Key Features
- Trauma-based Deckbuilding
- Shared dream generation affected by party traumas
- Emotional narrative + dark humor
- Co-op 1-4 players

## Roadmap
- Phase 1: Core mechanics prototype
- Phase 2: Hub management
- Phase 3: Procedural dream system
- Phase 4: Polish & Steam release
